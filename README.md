# Mini-Project---SQL-From-Data-to-Insight
SQL Project - Week 3
### Uso de las Redes Sociales en Adolescentes. Impacto en la salud mental y el rendimiento académico
---

## Objetivo del proyecto

Este proyecto analiza el uso de las redes sociales en adolescentes y su posible impacto en la salud mental y el rendimiento académico a partir de un dataset.

## Dataset:

**Teen Social Media Usage and Mental Health** — Kaggle

**Variables analizadas:**
- Uso diario de redes sociales (horas)
- Uso de redes sociales antes de dormir (horas)
- Nivel de estrés, ansiedad y depresión
- Rendimiento académico
- Datos demográficos: edad y género
---

## Preguntas de investigación

- ¿Qué plataforma utilizan más los adolescentes, tanto de día como de noche?
- ¿Existen diferencias en el uso de redes sociales según el género?
- ¿Existen diferencias en el uso de redes sociales según la edad?

---

## Hipótesis

Mayor uso de RRSS hay mayor nivel de estrés 
Mayor uso de RRSS hay mayor nivel de ansiedad 
Mayor uso de RRSS hay mayor nivel de depresión
Mayor uso de RRSS hay peor rendimiento académico 

---

# Proceso de analisis

- Python: Limpieza, preparación de datos y visualización.
- MySQL: Diseño de base de datos y almacenamiento.
- SQL: Análisis mediante consultas.
- Matplotlib: Visualización de gráficas.
- Jupyter Notebook: Entorno de desarrollo.
- GitHub: Control de versiones y colaboración.

---

## Metodología

El proyecto siguió un flujo de trabajo en cuatro pasos:

**Paso 1 — Python:** Limpieza y preparación del dataset (tratamiento de nulos, normalización, tipado de columnas).

**Paso 2 — MySQL:** Diseño e implementación de la base de datos relacional y carga de los datos limpios.

**Paso 3 — SQL:** Análisis de los datos mediante consultas avanzadas (`JOIN`, `GROUP BY`, `HAVING`, subconsultas, etc.) para responder las preguntas de investigación.

**Paso 4 — Python:** Visualización de los resultados obtenidos con Pandas y Matplotlib.

---

## Principales resultados

**Uso por plataforma:**
- Instagram, TikTok y el uso combinado de ambas presentan un comportamiento similar tanto en horas de uso diario como en uso antes de dormir. No se encontraron diferencias significativas entre plataformas.

**Uso de redes vs nivel de estrés:**
- Se aprecia una ligera tendencia a mayor estrés con mayor uso de redes sociales, pero sin diferencias estadísticamente significativas entre los grupos de uso bajo, medio y alto.

---

## Conclusiones

- No se observa una relación clara entre el uso de redes sociales y las variables de salud mental o rendimiento académico analizadas.
- Las hipótesis planteadas no se cumplen con los datos disponibles.
- El uso de redes es similar entre plataformas (Instagram y TikTok), tanto de día como de noche.
- No se detectan diferencias significativas en el uso según género o edad.

---

## Obstáculos encontrados

- El dataset presenta **poca variabilidad** en sus valores, lo que dificulta identificar relaciones claras entre variables.
- Los resultados poco concluyentes complicaron una buena interpretación de los datos.

---

## Próximos pasos

- Incorporar datasets más completos o con mayor variabilidad.
- Incluir variables adicionales que puedan explicar mejor el impacto en la salud mental (por ejemplo, tipo de contenido consumido, interacciones sociales, etc.).
- Analizar no solo el tiempo de uso, sino **cómo** se utilizan las redes sociales.
